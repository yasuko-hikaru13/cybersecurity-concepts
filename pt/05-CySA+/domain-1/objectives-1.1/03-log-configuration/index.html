Configuração de Logs

DEFINIÇÃO

Configuração de Logs

A configuração de logs determina quais eventos são registados, quanto detalhe é capturado e para onde os logs são enviados.

NÍVEL

Debug

Máximo detalhe de diagnóstico.

NÍVEL

Info / Warning

Atividade operacional e condições que exigem atenção.

NÍVEL

Error / Critical

Falhas e condições graves.

EQUILÍBRIO

Sinal vs Ruído

Pouco logging reduz visibilidade; excesso aumenta ruído e armazenamento.

VISUAL MODEL

Escolher o nível de logging

Mais detalhe aumenta a visibilidade, mas também o volume e o ruído.

Dica de exame: Logging insuficiente reduz a visibilidade; logging excessivo aumenta o ruído e as necessidades de armazenamento.
