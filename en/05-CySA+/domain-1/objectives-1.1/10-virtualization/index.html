Virtualization

DEFINITION

Virtualization

Running multiple virtual machines (VMs) on a single physical host using a hypervisor.

TYPE 1

Bare Metal

Hypervisor runs directly on hardware.

TYPE 2

Hosted

Hypervisor runs on a host OS.

RISK

VM Escape

Escape from a VM to hypervisor/other VMs.

RISK

VM Sprawl

Unmanaged VMs increase attack surface.

MENTAL MODEL 01

Type 1 Virtualization — Bare Metal

The hypervisor runs directly on the physical hardware.

MENTAL MODEL 02

Type 2 Virtualization — Hosted

The hypervisor runs on top of a host operating system.
