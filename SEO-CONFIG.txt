SEO CONFIGURATION
=================
Before publishing, replace every occurrence of:
  __SITE_URL__
with the public base URL, without a trailing slash.

Examples:
  https://username.github.io/learnIT-with-hikaruAo
  https://learn.example.com

The generated Open Graph artwork is under:
  /assets/og/

It is generated as 1200x630 SVG markup for each HTML page.
Note: some social platforms have limited SVG support for og:image.
For maximum cross-platform compatibility, PNG/JPEG should be used later.
